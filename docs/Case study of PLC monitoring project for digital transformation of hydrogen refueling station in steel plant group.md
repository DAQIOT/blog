Case study of PLC Data Acquisition monitoring project for digital transformation of hydrogen refueling station in steel plant group
The digital transformation project under a certain steel group in Tianjin mainly addresses the Data Acquisition requirements encountered during the digital transformation process of hydrogen refueling stations in large steel mills in Tianjin. Key project requirements: The PLC equipment is already running and needs to collect data without modifying the program or affecting the operation of the PLC.
2. Requirement description
The five hydrogen refueling stations and one hydrogen production station constructed by the steel plant have some PLCs (brands including Siemens,[ABB](https://zhida.zhihu.com/search?content_id=266692630&content_type=Article&match_order=1&q=ABB&zhida_source=entity)）The customer wishes to complete the PLCData Acquisitionwithout modifying the program and upload it to the platform for data display and monitoring via 4G.

2、 Scheme Introduction
1. Introduction to the Plan
Adopting data acquisition IoT PLC Data AcquisitionGateway（[DAQ-GP-DPUPLCBOX](https://zhida.zhihu.com/search?content_id=266692630&content_type=Article&match_order=1&q=DAQ-GP-DPUPLCBOX&zhida_source=entity)）By connecting the device to the PLC through a network cable, the operating data of the PLC can be read. Users do not need to understand the existing program of the PLC, nor do they need to modify the PLC program. They only need to provide the internal program point table of the PLC. The module transmits the collected data to a remote server or cloud platform through 4G.
